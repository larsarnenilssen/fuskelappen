# Arkiv

Dokumentene fra byggingen av appen, fase 0–10 (29.09.–09.10.2026). De er flyttet hit uendret da prosjektet gikk over til drift (avgjørelse 105), og gjelder ikke lenger som oppdrag. Det som fortsatt gjelder, står i [DRIFT.md](../../DRIFT.md), [AGENTS.md](../../AGENTS.md) og avgjørelsene.

- [OPPDRAG.md](OPPDRAG.md): oppdraget med faste rammer, faser, leveranser, kontrollpunkter og eiers svar underveis. Kapittel 7 har de åpne punktene slik de sto da prosjektet gikk over til drift.
- [arbeidsordrer/](arbeidsordrer/): arbeidsordren for hver fase og pakke, forslagene med eiers svar og skissene (`bilder/`). `fase-11.md` (reklamefilm) er ikke påbegynt.

Lenker inni dokumentene peker dit filene lå før, og kan være brutt. Avgjørelsene og kommentarene i innholdet viser til stiene her.
